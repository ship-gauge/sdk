# Quickstart

1. Create a project and copy your ingest API key.
2. Install `@shipgauge/node` and record your first event.
3. Add `shipgauge init` and a smoke eval suite.
4. Wire the GitHub Action for CI gate checks.

See the full guide in the repository `docs/QUICKSTART.md`.
